# WaveSign — дизайн-система

> **Сайт WaveDay** (`index.html`, `css/site.css`) использует те же цветовые токены и шрифты Nunito / Unbounded, но **не копирует** лендинг студии: без Pixelify Sans, пиксельного меню, «заказать» и сетки каталога. Это отдельная продуктовая вёрстка.

Источник правды для **WaveSign Studio** — CSS в [index.html](../index.html) (блок `:root` и дальше). Страницы `services/*`, `privacy/`, `offer/`, `terms/`, `cookies/` генерируются скриптом [scripts/build-seo.mjs](../scripts/build-seo.mjs) из `index.html`, поэтому стили правим только в `index.html` и пересобираем: `npm run build:seo`.

Админка (`admin-src/`) — отдельная светлая/тёмная система на Tailwind, описана в конце.

---

## 1. Характер

Тёмный фиолетовый «неон-студийный» стиль: почти чёрный фон с фиолетовым градиентом, крупные широкие заголовки, светло-розовый текст, акцент — сиренево-розовый. Пиксельный логотип как фирменная деталь. Минимум декора: плоские карточки, тонкие линии, скругления только там, где они уже приняты.

Принципы:
- **Контраст через цвет, а не через рамки.** Рамки — тонкие (`1px`, прозрачные).
- **Один акцент.** Яркий цвет (`--accent`) только для hover, подписей и ссылок.
- **Заголовки громкие, текст спокойный.** Unbounded 600–800 против Nunito 600–800 приглушённым цветом.
- **Пиксельный шрифт — только логотип и гамбургер.** Не использовать для текста.
- **Анимации короткие и ненавязчивые** (см. раздел 7), всегда с `prefers-reduced-motion`.

### Прозрачности светлого текста `rgb(251,232,255)`

Единая шкала — не придумывать новые значения:

| Альфа | Для чего |
|---|---|
| `.86` | подписи в форме, активные пункты |
| `.72` | рамка кнопки, вторичный текст |
| `.68` | `--muted`, ссылки футера |
| `.58` | копирайт, ссылки на документы, подсказки |
| `.12` | `--line`, разделители |
| `.07` / `.06` | фон переключателя языка, чипы |
| `.045` | фон плиток галереи и медиа-контейнеров |

### Фон страницы (градиент)

Все внутренние страницы (`.content-page`, `.detail-page`) используют один рецепт:

```css
background:
  linear-gradient(180deg, rgba(21,14,32,.82) 0%, rgba(32,18,58,.78) 40%, rgba(94,53,175,.78) 100%),
  linear-gradient(rgba(251,232,255,.045) 1px, transparent 1px),
  linear-gradient(90deg, rgba(251,232,255,.045) 1px, transparent 1px);
background-size: auto, 55px 55px, 55px 55px;   /* тонкая сетка 55px */
mask-image: linear-gradient(180deg, #000 0%, rgba(0,0,0,.88) 40%, rgba(0,0,0,.5) 75%, transparent 100%);
```

Правило: градиент **растворяется в `--bg` внизу** (маска до `transparent`), футер прозрачный и лежит поверх него. Резкой границы перед футером быть не должно.

Меню (`.menu-view`) использует тот же градиент без сетки + радиальный блик `rgba(238,153,255,.13)`.

## 3. Типографика

Подключаются через Google Fonts: **Nunito** (400–900), **Unbounded** (500–800), **Pixelify Sans** (400–700).

| Роль | Шрифт | Параметры |
|---|---|---|
| Базовый текст | Nunito | `font-weight:700` на `body`, system-ui как запасной |
| Hero-заголовок | Unbounded | `800`, `clamp(44px, 5.7vw, 92px)`, `line-height:1.18` |
| Заголовок услуги (`.detail-title`) | Unbounded | `600`, `48px` (38/32 на малых), `line-height:.95`, `uppercase`, белый |
| Заголовки каталога и форм | Unbounded | `uppercase`, `600–800` |
| Название услуги в карточке | Nunito | `700`, `31px`, `line-height:1.05`, одна строка с `ellipsis` |
| Заголовки категорий (`.cat-heading`) | Nunito | `900`, `20px`, `uppercase` |
| Логотип (`.brand-text`) | Pixelify Sans | `400`, `35px` (меньше на мобильных), `letter-spacing:.02em`, `#c061ff`, мягкая тень `rgba(124,37,244,.28)` |
| Кнопка «заказать» | Nunito | `700`, `30px`, `lowercase` |
| Футер | Nunito | ссылки `14px`, нижняя строка `12px` |

Правила:
- Заголовки Unbounded — всегда `uppercase` для услуг и разделов, `letter-spacing:0`.
- Не смешивать Pixelify Sans с обычным текстом.
- Размеры заголовков задаются через `clamp()` или медиа-запросы, а не фиксированно.

## 4. Сетка и отступы

- Контейнер `.page-shell`: `width:min(1710px,100%)`, боковые отступы `58px`, на узких экранах `44 → 28 → 18 → 14px`.
- Каталог: три колонки `290px | 1fr | 134px` (фильтры · карточки · навигация).
- Шапка `.site-header`: высота `96px` (82px на ≤760px, 74px на ≤520px), сетка `1fr auto 1fr`.
- Галерея услуги: 1 колонка на мобильных, 2 колонки от `768px`, `gap:24px` (18px на мобильных), верхний отступ `64px`; широкие (`is-landscape`) и последний нечётный элемент занимают всю ширину.
- Карточка услуги: превью `aspect-ratio:3/4`.
- Футер: сетка `1.7fr .62fr .9fr`, `gap:80px`, внутренняя ширина `1280px`; нижняя строка (копирайт + ссылки на документы) на всю ширину.

### Брейкпоинты

`1440` · `1180` · `1024` · `900` · `768` · `760` · `680` · `520` · `430` · `380` · `340` px. Основные: **1180** (планшет), **768/760** (мобильный), **430** (узкий).

## 6. Компоненты

**Шапка.** Слева пиксельный гамбургер + логотип, справа «ЗАКАЗАТЬ» и переключатель RU/UA/EN. Гамбургер — SVG-фон (три полосы 10×1 в сетке 10×9, `#c061ff`), размер ~76% кнопки.

**Переключатель языка (`.lang-switch`).** Пилюля, фон `rgba(251,232,255,.06)`, активная кнопка светлее (`.12`), кнопки `40×30px`.

**Карточка услуги.** Превью 3:4, под ним название (Nunito 700) и плашка цены (`--hot`, `от $…`). Hover: название становится `--accent`, вокруг фото кольцо. Без картинки — плейсхолдер `--accent` с названием Unbounded тёмным цветом.

**Плашка цены.** Фон `--hot`, белый текст, высота 25–36px, `inline-flex`.

**Кнопка «заказать» (`.order-submit`).** Прозрачная, рамка 1.5px, текст `lowercase`, высота `62px` (54/46px на малых).

**Форма заказа.** Поля-«строки» с нижней линией, подпись (`.order-caption`) цветом `rgba(238,153,255,.86)` слева. Под кнопкой — строка согласия (`.order-consent`, 13px, `.58`, ссылки `--accent` с подчёркиванием).

**Галерея.** Плитки `18px`, рамка `--line`, фон `rgba(251,232,255,.045)`. Скриншоты сайтов клиентов должны быть в кадре **1400×933** (3:2) — тогда плитки в две колонки выравниваются; мобильные макеты собирать в широкий кадр на фиолетовом градиенте (`#1c1230 → #3a2470`), а не класть одиночный портрет.

**Футер.** Три колонки (бренд · навигация · контакты) + нижняя строка: слева `© год WaveSign Studio. Все права защищены.`, справа текстовые ссылки на документы через точки-разделители. Заголовки колонок — `--accent`, `uppercase`, `900`. **Никаких «кнопок-таблеток» и разделительной линии над нижней строкой.** Ссылки и копирайт — один размер (12px) и вес.

**Плашка cookie (`.cookie-notice`).** Фиксирована слева внизу (`24px`), ширина до `420px` (на ≤520px — на всю ширину с отступами 16px), стекло: градиент `rgba(30,18,52,.94) → rgba(21,14,32,.96)` + `backdrop-filter:blur(14px)`, рамка `rgba(251,232,255,.16)`. Кнопка «Понятно» — светлая пилюля (`--text` на `--bg`). Информационная: на сайте только функциональные cookie.

**Иконки.** Стрелка «назад» и стрелка закрытия меню — линейные SVG `stroke:currentColor`, закруглённые концы. Пиксельный стиль только у гамбургера.

**Юридические страницы.** Колонка 860px, фон — тот же градиент (фиксированный), заголовок Unbounded 700, текст Nunito 600 цветом `--muted`, ссылки `--accent`. Переключатель языка — как в шапке сайта.

## 7. Движение

- Переход между экранами: `opacity`, вход `.28s ease`, выход `.18s ease`.
- Hover/focus: `color`, `border-color`, `background-color` за `.16–.22s ease`.
- Плашка cookie: `opacity` + `translateY(16px)` за `.35s ease`, появляется через ~0.9 с.
- Шапка: «frost» плавно проявляется при прокрутке.
- Все анимации отключаются в `@media (prefers-reduced-motion: reduce)`.
- Анимировать только `opacity`, `transform`, цвета — не `width/height/top`.

---

## 8. Контент и язык

- Три языка: **RU (по умолчанию), UA, EN**. Язык хранится в `localStorage` и cookie `wavesign-lang`; валюта — `wavesign-currency`.
- Все видимые строки есть в трёх вариантах (`locales` в `index.html`, `LEGAL_LABELS`, тексты документов в [scripts/legal-content.mjs](../scripts/legal-content.mjs)).
- Цены: «от $…», валюты USD / EUR / RUB / UAH переключаются в карточке услуги.
- Тон: короткий, деловой, без восклицаний.

---

## 8а. Доступность

- Тёмный фон + светлый текст `#FBE8FF` — контраст высокий; не использовать текст светлее `.58` альфы для важной информации.
- Все интерактивные элементы имеют `:focus-visible` (смена цвета на `--accent`).
- Кнопки — настоящие `<button>`, иконки с `aria-label`; декоративные SVG с `aria-hidden`.
- Размер тач-цели гамбургера — от `34px`.

## 9. Админка (`admin-src/`)

Отдельная система на Tailwind, **не** фиолетовая: нейтральная светлая тема с тёмным вариантом по `prefers-color-scheme`. Шрифт — Inter. Токены в RGB-каналах (`rgb(var(--token) / <alpha>)`).

| Токен | Светлая | Тёмная |
|---|---|---|
| `bg` | `247 246 250` | `15 13 20` |
| `surface` | `255 255 255` | `24 21 32` |
| `surface-2` | `249 248 252` | `30 26 41` |
| `border` | `231 226 240` | `44 39 58` |
| `ink` | `24 21 33` | `244 241 250` |
| `muted` | `104 97 122` | `168 160 184` |
| `faint` | `148 138 165` | `120 112 138` |
| `brand` | `108 61 255` | — |
| `brand-soft` | `238 232 255` | — |
| `ok` / `warn` / `danger` | `22 128 92` / `168 108 20` / `200 46 62` | — |

Радиусы: `lg 12px`, `xl 16px`, `2xl 20px`. Тени: `card`, `pop`. Базовые компоненты: `admin-src/src/components/ui/` (Button, Input, Textarea, Modal, ConfirmDialog, DropdownMenu, toast).

## 10. Чек-лист при добавлении нового UI

1. Цвета — только из таблиц выше, прозрачности — из шкалы.
2. Заголовок — Unbounded `uppercase`, текст — Nunito.
3. Рамки `1px solid var(--line)`, радиус `18px` для медиа, `999px` для пилюль.
4. Стили — в `index.html`, затем `npm run build:seo`.
5. Три языка для всех строк.
6. Проверить на `1440`, `768`, `390` px и с `prefers-reduced-motion`.
7. Изображения — WebP (`npm run optimize:images`), ширина до 1400px.
